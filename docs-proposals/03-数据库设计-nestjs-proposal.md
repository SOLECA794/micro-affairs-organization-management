# 03 · 数据库设计

## 1. 设计约定

- 数据库：PostgreSQL 16，原生 UTF-8；
- 主键：统一 `BIGINT GENERATED BY DEFAULT AS IDENTITY`，命名 `id`；
- 时间字段：`created_at`、`updated_at`（TIMESTAMP），由应用写入；`deleted` 为逻辑删除标记（0 正常，1 删除，SMALLINT）；
- 命名：表名与字段名小写、下划线分隔，语义清晰；
- 计数用整数；状态字段用 VARCHAR 语义值（如 `PUBLISHED`）或 SMALLINT，全项目统一；
- **结构唯一来源**：`prisma/schema.prisma` 定义全部模型，迁移由 `prisma migrate` 生成并纳入版本管理；初始化数据用 Prisma seed 脚本（幂等）；
- 涉及名额与唯一性的表必须设置文档中声明的唯一约束与索引。

## 2. 实体关系概览

- 用户与社团：`association.leaderUserId` 关联负责人；
- 活动归属：`activity.associationId`、`activity.categoryId`；
- 报名：`signup` 关联活动与用户（一对多）；
- 签到：`attendance` 关联活动与用户（一对一）；
- 签到码：`signinCode` 关联活动；
- 通知：`notification` 关联用户；
- 日志：`operationLog` 记录用户动作。

| 表名 | 用途 |

## 4. 表结构明细

### 4.1 User（用户）

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT | PK, IDENTITY | 用户 ID |
| username | VARCHAR(50) | UNIQUE, NOT NULL | 登录账号 |
| password | VARCHAR(100) | NOT NULL | argon2 密文 |
| realName | VARCHAR(50) | NOT NULL | 姓名 |
| phone | VARCHAR(20) | 可空 | 手机号 |
| role | VARCHAR(20) | NOT NULL | STUDENT / MANAGER / ADMIN |
| avatar | VARCHAR(255) | 可空 | 头像地址 |
| status | SMALLINT | DEFAULT 1 | 1 正常，0 停用 |
| deleted | SMALLINT | DEFAULT 0 | 逻辑删除 |
| createdAt | TIMESTAMP | NOT NULL | 创建时间 |
| updatedAt | TIMESTAMP | NOT NULL | 更新时间 |

索引：`idx_user_role(role)`。

### 4.2 Association（社团）

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT | PK, IDENTITY | 社团 ID |
| name | VARCHAR(100) | NOT NULL | 社团名称 |
| code | VARCHAR(30) | UNIQUE, NOT NULL | 社团编号 |
| category | VARCHAR(50) | 可空 | 社团分类（文本） |
| leaderUserId | BIGINT | NOT NULL | 负责人用户 ID，关联 User |
| status | SMALLINT | DEFAULT 1 | 1 正常，0 停用 |
| description | VARCHAR(500) | 可空 | 简介 |
| deleted | SMALLINT | DEFAULT 0 | 逻辑删除 |
| createdAt | TIMESTAMP | NOT NULL | 创建时间 |
| updatedAt | TIMESTAMP | NOT NULL | 更新时间 |

索引：`idx_assoc_leader(leaderUserId)`。

### 4.3 ActivityCategory（活动分类）

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT | PK, IDENTITY | 分类 ID |
| name | VARCHAR(50) | NOT NULL, UNIQUE | 分类名 |
| sort | INT | DEFAULT 0 | 排序 |

### 4.4 Activity（活动）

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT | PK, IDENTITY | 活动 ID |
| associationId | BIGINT | NOT NULL | 所属社团，关联 Association |
| categoryId | BIGINT | 可空 | 分类，关联 ActivityCategory |
| title | VARCHAR(100) | NOT NULL | 活动标题 |
| cover | VARCHAR(255) | 可空 | 封面地址 |
| description | TEXT | 可空 | 活动简介 |
| location | VARCHAR(200) | NOT NULL | 地点 |
| startTime | TIMESTAMP | NOT NULL | 开始时间 |
| endTime | TIMESTAMP | NOT NULL | 结束时间 |
| signupDeadline | TIMESTAMP | NOT NULL | 报名截止时间 |
| capacity | INT | NOT NULL | 名额上限 |
| enrolledCount | INT | DEFAULT 0 | 当前报名成功数 |
| status | VARCHAR(20) | NOT NULL | DRAFT/PENDING/APPROVED/REJECTED/PUBLISHED/CANCELLED/ENDED/ARCHIVED |
| auditComment | VARCHAR(500) | 可空 | 审核意见 |
| createdBy | BIGINT | NOT NULL | 创建人（负责人） |
| deleted | SMALLINT | DEFAULT 0 | 逻辑删除 |
| createdAt | TIMESTAMP | NOT NULL | 创建时间 |
| updatedAt | TIMESTAMP | NOT NULL | 更新时间 |

索引：`idx_act_assoc(associationId)`、`idx_act_status(status)`、`idx_act_start(startTime)`。
约束：`CHECK (capacity > 0)`；报名截止不晚于开始时间由应用层校验并在 schema 保留约束。

### 4.5 Signup（报名）

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT | PK, IDENTITY | 报名 ID |
| activityId | BIGINT | NOT NULL | 活动，关联 Activity |
| userId | BIGINT | NOT NULL | 用户，关联 User |
| status | VARCHAR(20) | NOT NULL | ACTIVE / WAITING / CANCELLED |
| queueOrder | INT | DEFAULT 0 | 候补序号（非候补为 0） |
| signupTime | TIMESTAMP | NOT NULL | 报名时间 |
| cancelTime | TIMESTAMP | 可空 | 取消时间 |

约束与索引：
- `UNIQUE uk_signup(activityId, userId)`：防重复报名；
- `idx_signup_activity(activityId, status)`：名单与候补查询；
- `idx_signup_user(userId)`：我的报名查询。

### 4.6 Attendance（签到）

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT | PK, IDENTITY | 签到 ID |
| activityId | BIGINT | NOT NULL | 活动 |
| userId | BIGINT | NOT NULL | 用户 |
| signType | VARCHAR(20) | NOT NULL | QR（扫码）/ MANUAL（补签） |
| signTime | TIMESTAMP | NOT NULL | 签到时间 |
| operatorId | BIGINT | 可空 | 补签操作人（扫码为空） |

约束与索引：
- `UNIQUE uk_attendance(activityId, userId)`：防重复签到；
- `idx_att_activity(activityId)`。

### 4.7 SigninCode（签到码）

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT | PK, IDENTITY | 签到码 ID |
| activityId | BIGINT | NOT NULL | 活动 |
| token | VARCHAR(64) | UNIQUE, NOT NULL | 随机 Token（UUID） |
| expiresAt | TIMESTAMP | NOT NULL | 过期时间 |
| status | SMALLINT | DEFAULT 1 | 1 有效，0 已作废 |
| createdBy | BIGINT | NOT NULL | 开启人 |
| createdAt | TIMESTAMP | NOT NULL | 生成时间 |

索引：`idx_code_activity(activityId, status)`。

### 4.8 Notification（站内通知）

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT | PK, IDENTITY | 通知 ID |
| userId | BIGINT | NOT NULL | 接收人 |
| type | VARCHAR(30) | NOT NULL | AUDIT/SIGNUP/WAITING/PROMOTED/CANCELLED/SIGNIN |
| title | VARCHAR(100) | NOT NULL | 标题 |
| content | VARCHAR(500) | 可空 | 内容 |
| readStatus | SMALLINT | DEFAULT 0 | 0 未读，1 已读 |
| createdAt | TIMESTAMP | NOT NULL | 创建时间 |

索引：`idx_notify_user(userId, readStatus)`。

### 4.9 OperationLog（操作日志）

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT | PK, IDENTITY | 日志 ID |
| userId | BIGINT | 可空 | 操作人 |
| module | VARCHAR(30) | NOT NULL | 模块（auth/signup/signin/activity/admin） |
| action | VARCHAR(50) | NOT NULL | 动作描述 |
| detail | VARCHAR(500) | 可空 | 详情 |
| ip | VARCHAR(50) | 可空 | 来源 IP |
| createdAt | TIMESTAMP | NOT NULL | 时间 |

索引：`idx_log_user(userId)`、`idx_log_time(createdAt)`。

## 5. 并发与一致性设计汇总

| 场景 | 数据库保障 | 说明 |
| --- | --- | --- |
| 重复报名 | uk_signup 唯一约束 | 并发插入仅一条成功 |
| 超额报名 | 条件 UPDATE enrolled_count < capacity | 与插入同一事务 |
| 重复签到 | uk_attendance 唯一约束 | 并发扫码仅一条成功 |
| 重复递补 | 递补仅在取消事务内执行 | 事务隔离保证顺序性 |
| 逻辑删除 | deleted 字段 + 查询过滤 | 避免物理删除破坏唯一约束历史 |

## 7. 结构与脚本管理

- `prisma/schema.prisma`：全部模型定义（含索引、唯一约束、映射表名），是数据库结构的唯一来源；
- 迁移：`prisma migrate dev --name xxx` 生成增量迁移，纳入版本管理；`prisma migrate deploy` 用于部署环境；
- 初始化：`prisma/seed.ts` 写入初始化数据，可重复执行（幂等）；
- 变更流程：结构变更先改 schema → 生成迁移 → 同步更新本文档对应表 → 全组评审后合并。
